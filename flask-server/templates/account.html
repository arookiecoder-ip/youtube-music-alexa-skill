    Password

    Changing it signs out every other device and leaves this one signed in, so a stolen password cannot keep a stranger's session alive.

    At least {{ password_min_length }} characters, two of: lowercase, uppercase, digit, symbol. Not your username.

    Two-factor sign-in {{ 'On' if totp_enabled else ('Setup waiting' if totp_pending else 'Off') }}

    An authenticator app on your phone adds a six-digit code at sign-in. Your password alone stops being enough.

    Turn it on and you will need both your password and the code to sign in, from either door.

    1. Add a setup key in your authenticator app, or scan the code.
    2. Otherwise type the secret below, with Time-based (TOTP) selected.
    3. Enter the six-digit code the app shows to confirm.

    {%- if totp_pending -%} A setup is already waiting. Scan the code or confirm it, or cancel and start again. {%- endif -%}

    Turning it off asks for both your password and a live code, so a lost phone cannot be used to strip the second factor by someone who only has the password.
